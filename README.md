# VIZELEC - Ingeniería Eléctrica, SCADA y Automatización Industrial

Landing page corporativa moderna y minimalista de estética **Premium Dark-Tech** para **VIZELEC** (Consultora de Victorio Zabalet).

## 🚀 Tecnologías y Características Visuales

- **Core Estático**: Desarrollado con HTML5 semántico y Javascript nativo (ES6) para una carga ultra veloz.
- **Estética Premium Dark-Tech**: Diseñado utilizando variables HSL personalizadas con fondos oscuros profundos, azules eléctricos, verdes de energías renovables y bordes semi-transparentes con efecto *Glassmorphism*.
- **Interactividad y Micro-animaciones**:
  - **Sticky Header**: Barra de navegación con desenfoque de fondo esmerilado de `20px` (`backdrop-filter`) que se activa al hacer scroll.
  - **Gráfico SVG Animado**: Animaciones CSS nativas tridimensionales en el Hero que simulan flujos de potencia, osciloscopios SCADA y automatización.
  - **Efecto Linterna**: Foco de luz difusa azul eléctrica que sigue al mouse del usuario sobre las tarjetas de servicios especializados.
  - **Sliders Multimedia**: Carruseles interactivos locales en los casos de éxito (ET Tres Lomas, ET San Manuel, Central Cerro Dragón, Central Barker, ET Miramar, Pliego Suárez-Guaminí, etc.) con controles fluidos de flechas y dots indicadores esmerilados.
  - **Formulario Inteligente**: Floating labels, validaciones de campos en tiempo real y simulación premium de procesamiento de envío con bloqueo de seguridad y spinners dinámicos.
- **Sección de Servicios Optimizada**: Rediseño compacto que reduce más de 350 píxeles de scroll vertical para un acceso directo a los casos de éxito.
- **Arquitectura Local Estática**: Carpeta `public/images/` que almacena de forma segura las 25 fotos y planos reales del catálogo técnico.

## 🛠️ Instrucciones de Despliegue Local
